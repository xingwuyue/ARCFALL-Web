# 手机浏览器版

Web 导出文件位于 `build/web/`，完整分发包为 `build/ARCFALL-Web.zip`。导出使用 Godot WebGL 2 Compatibility 渲染、单线程模板和 PWA 离线缓存。

## 手机上打开

把 ZIP 解压后，将文件夹中的全部内容上传到支持 HTTPS 的静态网站托管，打开该站点的 `index.html`。上传时保持文件名和目录结构不变。首次打开需要下载游戏资源；加载完成后，浏览器会缓存资源，可以在信号较差或离线时再次打开。需要安装到主屏幕时，在浏览器菜单中选择“添加到主屏幕”。

也可以在电脑和手机连接同一 Wi-Fi 时，用电脑临时提供网页：双击包内的 `run-local-web.cmd`，再在电脑上运行 `ipconfig` 找到局域网 IPv4 地址，在手机浏览器访问 `http://电脑地址:8000/`。如果 Windows 防火墙询问，允许 Python 在专用网络通信。此临时方式适合试玩；PWA 安装和离线缓存建议使用 HTTPS 托管。

不要从手机文件管理器直接点击 `index.html`：浏览器会限制 `file://` 页面读取 WebAssembly 和游戏资源。成绩保存在当前浏览器的本地存储中；清除浏览器数据或更换设备后不会自动同步。

## 重新导出

在项目根目录运行 `powershell -ExecutionPolicy Bypass -File tools/export_mobile_web.ps1`。本机需要与项目版本一致的 Godot 4.7.2 和 Web 导出模板。

当前 Web 导出使用 ETC2 移动端纹理压缩，PCK 约 56 MiB，WebAssembly 约 38 MiB；分发 ZIP 约 50 MiB。静态托管启用 gzip 后首次传输量还会更小。该网页包适合 HTTPS 静态托管；直接把 ZIP 发到手机并不会变成可离线安装的网页。
